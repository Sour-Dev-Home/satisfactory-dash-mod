# Spikes S6 and S7 (claims C8 and C9) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove, with harness-written evidence on the runner, that a mod can read every status field natively (C8,
spike S6) and read and change auto-pause natively (C9, spike S7), matching the vanilla API at the same moment.

**Architecture:** Two throwaway spike plugins, built and run by the existing G2 harness exactly like S3: the server
boots, the harness loads the staged save, and the harness pairs each line the mod logs with a vanilla API call made
right after it. The harness gains a "world" mode shared by S3, S6 and S7, two collectors (status, auto-pause steps)
and two pass rules. This is Plan 1 of the core mod (sub-project 2); Plan 2, the build, is written after these pass
because it uses the symbols they prove.

**Native means in-process.** `UFGServerSubsystem::GetServerGameState()` returns the same `FServerGameState` that
`Handler_QueryServerState` fills (`FGServerSubsystem.h:140`, `FGServerStateController.h:32`). Tick health and the
server options have no getter, so the mod creates its own `UFGServerStateController` / `UFGServerManagementController`
under the server's API manager and calls the game's own `Handler_HealthCheck`, `Handler_GetServerOptions` and
`Handler_ApplyServerOptions` in-process. Controllers find the subsystem through their outers
(`FGServerControllerBase.h:17`; the API manager's outer is the subsystem, `FGServerAPIManager.h:183`). No HTTP. If
that fails at runtime, the spike fails, and the spec's fallback (loopback HTTP for that field) goes back to the owner.

**Tech Stack:** UE 5.6.1 (CSS build) + SML 3.12.0 C++ plugins; the harness in Node/TypeScript with Vitest.

**Spec:** `docs/specs/2026-10-20-core-mod-v1-design.md`, section "Spikes before the build: C8 and C9" (approved by the
owner 2026-10-20, mod PR #19).

## Global Constraints

- Toolchain: engine `5.6.1`, SML `3.12.0` (`harness/toolchain.json`); the runner refuses a mismatch.
- Every SML, FactoryGame or engine symbol, include and module dependency under `spikes/` has an `api-sources.md` row
  whose header `path:line` was looked up in the pinned checkout, never written from memory (`api-sources.md` rules).
- Spikes log only through `DEFINE_LOG_CATEGORY_STATIC(LogSatisMod, Display, All)`, every line starting `satis-mod`.
- Bundles are public: no session name (only the first 12 hex characters of its SHA-1 over UTF-8), no token, and no
  server option other than `FG.DSAutoPause`.
- S6 and S7 load the staged save, so, like S3, they run only as `satis-runner` (the harness refuses when another
  server's `ServerSettings.<port>.sav` shares the saves folder). They are offered on the runner, not local-only.
- Auto-pause is put back as it was found, whatever happens during the run.
- Nothing personal and no absolute local path is committed. Never push to `main`; one PR for the whole plan.
- Harness tests: narrow first (`npx vitest run test/<file>.test.ts --reporter=dot` from `harness/`), `npm test` once at
  the end of each task.

## Review Focus

1. **Lines already in the log when a phase's collector starts** (the mod logged while the harness was loading the
   world). Paired with a late API read, they'd compare different moments. Expected: S6 discards the first batch it
   reads in each phase. Test: Task 1, "skips the backlog it finds on its first read".
2. **A session name with non-ASCII characters.** Expected: both sides hash the UTF-8 bytes, so the hashes match.
   Test: Task 1, "hashes a non-ASCII session name over its UTF-8 bytes".
3. **The API is briefly unreachable during a phase** (the save is loading). Expected: that pair keeps `api: null`, is
   not judged, and counts against the minimum, so a run that saw too few is a FAIL with the count. Tests: Task 1
   "keeps a failed API read as null", Task 2 "fails with the count when too few pairs were judged".
4. **The run dies between S7's change and its restore.** Expected: the harness restores the value it read before the
   mod acted. Test: Task 4, "S7: restores auto-pause even when collecting fails".
5. **A runner config with the world but without FRM.** Expected: S6 and S7 run (they don't need FRM); S3 still refuses
   with its own message. Test: Task 4, "S6: runs with s3World and no frmBaseUrl" and the existing S3 refusal test.

```ts
// S6 (claim C8): the mod's native status readings, paired with QueryServerState and HealthCheck read right after.
import { createHash } from "node:crypto";
import type { StatusPair, StatusReading } from "./verdict";

/** The first 12 hex characters of the name's SHA-1 over UTF-8. The mod logs the same, so names stay out of bundles. */
export const sessionHash = (name: string) => createHash("sha1").update(name, "utf8").digest("hex").slice(0, 12);

const S6 = /satis-mod s6 running=([01]) paused=([01]) players=(\d+) limit=(\d+) duration=(\d+) tick=([\d.]+) health=(\S*) session=([0-9a-f]{12})/;

export function parseS6Line(line: string): StatusReading | null {
  const m = S6.exec(line);
  if (!m) return null;
  return {
    running: m[1] === "1",
    paused: m[2] === "1",
    players: Number(m[3]),
    limit: Number(m[4]),
    duration: Number(m[5]),
    tickRate: Number(m[6]),
    health: m[7]!,
    session: m[8]!,
  };
}

type Api = { call(fn: string, data?: Record<string, unknown>): Promise<{ status: number; body: unknown }> };

/** As satisfactory-dash reads them (packages/game-adapter/src/satisfactoryServerAdapter.ts:146-171). */
export async function readApiStatus(api: Api): Promise<StatusReading> {
  const q = await api.call("QueryServerState");
  if (q.status < 200 || q.status > 299) throw new Error(`QueryServerState returned ${q.status}`);
  const s = (q.body as { data?: { serverGameState?: Record<string, unknown> } } | null)?.data?.serverGameState;
  if (!s) throw new Error("QueryServerState has no serverGameState");
  const h = await api.call("HealthCheck", { ClientCustomData: "" });
  if (h.status < 200 || h.status > 299) throw new Error(`HealthCheck returned ${h.status}`);
  const health = (h.body as { data?: { health?: unknown } } | null)?.data?.health;
  if (typeof health !== "string") throw new Error("HealthCheck has no health");
  // The tick rate is rounded as the mod logs it (%.2f), so equal values compare equal.
  return {
    running: s.isGameRunning === true,
    paused: s.isGamePaused === true,
    players: Number(s.numConnectedPlayers),
    limit: Number(s.playerLimit),
    duration: Number(s.totalGameDuration),
    tickRate: Number(Number(s.averageTickRate).toFixed(2)),
    health,
    session: sessionHash(String(s.activeSessionName ?? "")),
  };
}

export async function collectStatusPairs(opts: {
  readNew: () => string[];
  api: () => Promise<StatusReading>;
  sleep: (ms: number) => Promise<void>;
  now: () => number;
  durationMs: number;
  intervalMs: number;
  want: number;
  /** Discard what the first read finds: those lines were logged before this phase's collector started. */
  skipBacklog: boolean;
}): Promise<StatusPair[]> {
  const pairs: StatusPair[] = [];
  const end = opts.now() + opts.durationMs;
  let first = true;
  while (opts.now() < end && pairs.length < opts.want) {
    const lines = opts.readNew();
    if (!(first && opts.skipBacklog)) {
      for (const l of lines) {
        const mod = parseS6Line(l);
        if (!mod) continue;
        let api: StatusReading | null = null;
        try { api = await opts.api(); } catch { api = null; }
        pairs.push({ at: new Date(opts.now()).toISOString(), mod, api });
      }
    }
    first = false;
    if (pairs.length < opts.want) await opts.sleep(opts.intervalMs);
  }
  return pairs;
}
```

```ts
// S6 (claim C8): every status field the mod reads natively matches QueryServerState and HealthCheck read right after,
// both without a world (the entry map) and with one.
import type { Evidence, StatusReading, Verdict } from "../../harness/src/verdict";

export const claim = "C8";
const NEED = 10;
/** One round is 10 s, so a reading taken up to a round later may be that far ahead (spec: "one round's drift"). */
const DURATION_DRIFT = 10;
const tickClose = (a: number, b: number) => Math.abs(a - b) <= Math.max(2, 0.1 * Math.max(a, b));
const EXACT: { key: keyof StatusReading; name: string }[] = [
  { key: "running", name: "running" },
  { key: "paused", name: "paused" },
  { key: "players", name: "players" },
  { key: "limit", name: "limit" },
  { key: "health", name: "health" },
  { key: "session", name: "session" },
];

export function evaluate(e: Evidence): Verdict {
  if (!e.status) return { pass: false, reasons: ["the harness collected no status readings"] };
  const reasons: string[] = [];
  const judged = e.status.pairs.filter((p) => p.api !== null);
  const without = judged.filter((p) => !p.api!.running).length;
  const withWorld = judged.length - without;
  if (without < NEED) reasons.push(`${without} readings without a world, need ${NEED}`);
  if (withWorld < NEED) reasons.push(`${withWorld} readings with a world, need ${NEED}`);
  for (const p of judged) {
    const api = p.api!;
    for (const { key, name } of EXACT) if (p.mod[key] !== api[key]) reasons.push(`${p.at}: ${name} ${p.mod[key]} vs API ${api[key]}`);
    if (Math.abs(p.mod.duration - api.duration) > DURATION_DRIFT) reasons.push(`${p.at}: duration ${p.mod.duration} vs API ${api.duration}`);
    if (!tickClose(p.mod.tickRate, api.tickRate)) reasons.push(`${p.at}: tick rate ${p.mod.tickRate} vs API ${api.tickRate}`);
  }
  return reasons.length
    ? { pass: false, reasons }
    : { pass: true, reasons: [`${without} readings without a world and ${withWorld} with one: every field matches QueryServerState and HealthCheck`] };
}
```

```markdown
Part of the core mod's spec (`docs/specs/2026-10-20-core-mod-v1-design.md`, "Spikes before the build").

**What the mod does.** On each new game world it logs one line every 10 s, 15 times:
```

```ts
// S7 (claim C9): each auto-pause step the mod logs, paired with GetServerOptions read right after it.
import type { AutoPauseStep, AutoPauseStepName } from "./verdict";

const S7 = /satis-mod s7 step=(read|set|check|restore|final) value=(True|False)(?: pending=([01]))?/;

export function parseS7Line(line: string): { step: AutoPauseStepName; value: boolean; pending: boolean | null } | null {
  const m = S7.exec(line);
  if (!m) return null;
  return { step: m[1] as AutoPauseStepName, value: m[2] === "True", pending: m[3] === undefined ? null : m[3] === "1" };
}

export async function collectAutoPauseSteps(opts: {
  readNew: () => string[];
  api: () => Promise<boolean>;
  sleep: (ms: number) => Promise<void>;
  now: () => number;
  durationMs: number;
  intervalMs: number;
}): Promise<AutoPauseStep[]> {
  const steps: AutoPauseStep[] = [];
  const end = opts.now() + opts.durationMs;
  while (opts.now() < end) {
    for (const l of opts.readNew()) {
      if (l.includes("satis-mod s7 done")) return steps;
      const s = parseS7Line(l);
      if (!s) continue;
      let api: boolean | null = null;
      try { api = await opts.api(); } catch { api = null; }
      steps.push({ at: new Date(opts.now()).toISOString(), step: s.step, mod: s.value, pending: s.pending, api });
    }
    await opts.sleep(opts.intervalMs);
  }
  return steps;
}
```

```ts
// S7 (claim C9): the mod reads auto-pause natively, changes it, and puts it back; GetServerOptions, read after each
// step, agrees every time, and no change is left pending.
import type { AutoPauseStep, Evidence, Verdict } from "../../harness/src/verdict";

export const claim = "C9";
const ORDER: AutoPauseStep["step"][] = ["read", "set", "check", "restore", "final"];
const word = (b: boolean) => (b ? "True" : "False");

export function evaluate(e: Evidence): Verdict {
  if (!e.autoPause) return { pass: false, reasons: ["the harness collected no auto-pause steps"] };
  const reasons: string[] = [];
  const by = new Map(e.autoPause.steps.map((s) => [s.step, s]));
  for (const name of ORDER) if (!by.has(name)) reasons.push(`the mod never logged step=${name}`);
  for (const s of e.autoPause.steps) {
    if (s.api === null) reasons.push(`${s.step}: GetServerOptions failed`);
    else if (s.api !== s.mod) reasons.push(`${s.step}: mod ${word(s.mod)} vs GetServerOptions ${word(s.api)}`);
    if (s.pending === true) reasons.push(`${s.step}: the option is still pending`);
  }
  const read = by.get("read");
  if (read) {
    const expect = { set: !read.mod, check: !read.mod, restore: read.mod, final: read.mod } as const;
    for (const [name, want] of Object.entries(expect) as [keyof typeof expect, boolean][]) {
      const s = by.get(name);
      if (s && s.mod !== want) reasons.push(`${name}: ${word(s.mod)}, but the mod read ${word(read.mod)} first`);
    }
  }
  return reasons.length || !read
    ? { pass: false, reasons }
    : { pass: true, reasons: [`auto-pause read ${word(read.mod)}, changed to ${word(!read.mod)} and back natively; GetServerOptions agreed at all five steps`] };
}
```

```ts
/** Reads the log from `from` on, a poll at a time: only whole lines (a poll can land mid-write) that contain marker. */
export function lineReader(path: string, from: number, marker: string): { readNew(): string[]; offset(): number } {
  let seen = from;
  return {
    readNew: () => {
      // readLogSince's offset is in bytes.
      const text = readLogSince(path, seen);
      const whole = text.slice(0, text.lastIndexOf("\n") + 1);
      seen += Buffer.byteLength(whole, "utf8");
      return whole.split(/\r?\n/).filter((l) => l.includes(marker));
    },
    offset: () => seen,
  };
}
```

```cpp
void FSatisModS7Module::StartupModule()
{
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod loaded"));
	WorldInitHandle = FWorldDelegates::OnPostWorldInitialization.AddLambda([this](UWorld* InWorld, const UWorld::InitializationValues)
	{

		// Only the loaded save matters here; the entry map's world is replaced before the first step runs.
		World = InWorld;
		Step = 0;
		Original.Reset();
		FTSTicker::RemoveTicker(FirstHandle);
		FTSTicker::RemoveTicker(EveryHandle);
		// 60 s for the harness to record the value first, then one step every 15 s so it can read the API between them.

			{
				EveryHandle = FTSTicker::GetCoreTicker().AddTicker(TEXT("SatisModS7Every15s"), 15.0f, [this](float) { return RunStep(); });
			}
			return false;
		});
	});
}

bool FSatisModS7Module::RunStep()
{
	UFGServerSubsystem* Server = World.IsValid() ? UFGServerSubsystem::Get(World.Get()) : nullptr;
	UFGServerAPIManager* Manager = Server != nullptr ? Server->GetServerAPIManager() : nullptr;
	if (Manager == nullptr)
	{
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 error=no-api-manager"));
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 done"));
		return false;
	}
	switch (Step++)
	{
	case 0:
		Original = Read(Manager, TEXT("read"));
		if (Original.IsEmpty())
		{
			UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 done"));
			return false;
		}
		return true;
	case 1:
		Apply(Manager, Original == TEXT("True") ? TEXT("False") : TEXT("True"), TEXT("set"));
		return true;
	case 2:
		Read(Manager, TEXT("check"));
		return true;
	case 3:
		Apply(Manager, Original, TEXT("restore"));
		return true;
	default:
		Read(Manager, TEXT("final"));
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 done"));
		return false;
	}
}

FString FSatisModS7Module::Read(UFGServerAPIManager* Manager, const TCHAR* StepName) const
{
	// The game's own GetServerOptions handler, in-process. The options also hold FRM's token: only ours is touched.
	TMap<FString, FString> Options;
	TMap<FString, FString> Pending;
	NewObject<UFGServerStateController>(Manager)->Handler_GetServerOptions(Options, Pending);
	const FString* Value = Options.Find(AutoPauseOption);
	if (Value == nullptr || (*Value != TEXT("True") && *Value != TEXT("False")))
	{
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 error=no-option step=%s"), StepName);
		return FString();
	}
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 step=%s value=%s pending=%d"), StepName, **Value, Pending.Contains(AutoPauseOption) ? 1 : 0);
	return *Value;
}

void FSatisModS7Module::Apply(UFGServerAPIManager* Manager, const FString& Value, const TCHAR* StepName) const
{
	TMap<FString, FString> Updated;
	Updated.Add(AutoPauseOption, Value);
	NewObject<UFGServerManagementController>(Manager)->Handler_ApplyServerOptions(Updated);
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod s7 step=%s value=%s"), StepName, *Value);
}
```
