# G2 Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Node/TypeScript harness and a locked-down self-hosted workflow that build each ADR-0039 spike, run it on a
test dedicated server, judge its claim in code and write the evidence, so spikes S0, S1, S1b and S2 can run the moment
the owner's toolchain is installed.

**Architecture:** `harness/` is one npm package of small modules (config, check-api, contract, echo, log watcher, server
API, tick sampler, server control, evidence, run orchestration, CLI), each unit-tested with fakes on GitHub's hosted
runner. `spikes/S#/pass.ts` holds each spike's pass condition as code. `spike.yml` runs the harness on the owner's
self-hosted `ue` runner, only on `workflow_dispatch` or a push to `main`, behind the `ue-runner` approval environment.
The spike mods themselves (C++) are **not** in this plan: they are written in a follow-up plan after G2-prep, against
real headers, because writing them now would mean writing APIs from memory.

**Tech Stack:** Node 22, TypeScript (`typescript@~7.0.2`), zod 4, vitest 5, tsx, `yaml`; GitHub Actions.

**Spec:** `docs/specs/2026-10-19-g2-harness-design.md` (approved by the owner, 2026-10-19).

## Global Constraints

- Node 22 (`harness/.node-version`), ESM (`"type": "module"`), zod `^4.6.6`, vitest `^5.0.3`, typescript `~7.0.2`,
  matching satisfactory-dash. Install with the `npm install` commands given in Task 1; never hand-write a version
  number into `package.json`.
- Actions are pinned by SHA, exactly: `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7`,
  `actions/setup-node@949feb2413d6458794dcd2491c4babbbce0c15c1 # v7`,
  `actions/upload-artifact@cf430e030ddbb5b0abf93d22962f4752f3646cd9 # v7.0.2`.
- **No API from memory.** Nothing in this plan calls an SML, FactoryGame or engine API. Everything about the game server
  comes from a captured source in satisfactory-dash `docs-vault/raw-sources/`, cited in a code comment:
  - the `/api/v1` POST shape and `averageTickRate` come from `captured-responses/vanilla-QueryServerState-*`;
  - `HealthCheck` (no auth), `Shutdown` and the `AllowInsecureLocalAccess` argument come from `dedicated-server-api.md`;
  - the mod folders come from `sml-manual-install.md`;
  - the log path comes from `sml-dedicated-servers-2026-09-27.adoc`.
- **Unsourced values live only in the runner's config, never in code.** These are the server's ports, the Alpakit build
  command, and where a test save goes. The harness refuses to run while a required one is missing.
- **Loopback only:** the server API client refuses any host but `127.0.0.1`, `localhost` or `[::1]`, and the echo server
  binds `127.0.0.1`.
- **No PII or local paths** (absolute paths under a user profile) committed. Evidence bundles redact home-directory paths, and the full server
  log never goes into a bundle; it stays on the runner.
- **The spike contract** that the follow-up spikes plan must honour, and that this plan's pass conditions check:
  - plugin names: `SatisModS0`, `SatisModS1`, `SatisModS1b`, `SatisModS2`;
  - log lines:
    - `satis-mod loaded` (every spike, at module startup);
    - `satis-mod s1 done`;
    - `satis-mod s1b good status=<n>`;
    - `satis-mod s1b bad error=<text>` or `satis-mod s1b bad status=<n>`;
    - `satis-mod s2 done`;
  - echo: `http://127.0.0.1:18080`. S1 POSTs `{"spike":"S1","hello":"satis"}` to `/s1` with
    `Content-Type: application/json`. S2 POSTs `{"spike":"S2","n":<1..40>}` to `/s2` every 30 s, exactly 40 times,
    then logs `satis-mod s2 done`.
- **Two PRs to `main`, both plain PRs** (no lanes in this repo), merged by the owner:
  - PR A: Tasks 1–9, branch `feat/g2-harness`;
  - PR B: Task 10, branch `feat/g2-runner`, opened after PR A merges.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; every PR body ends with
  `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Run tests narrowly while working (`npx vitest run test/<file>.test.ts --reporter=dot` from `harness/`), and the full
  suite (`npm test`) plus `npm run typecheck` before each commit.

## Review Focus

1. **The owner's real server is up on the same ports when a spike starts.** Expected: the test server fails health, and
   the harness records a failed run and stops only the process it spawned, never another. Pinned in Task 7
   (`stopServer kills only the spawned pid`) and Task 9 (`stops the process it started`).
2. **A previous run's log already contains `satis-mod loaded`.** Expected: only lines written after this run's start
   count. Pinned in Task 5 (`ignores lines before fromOffset`) and Task 9 (the offset is read before `start`).
3. **A spike mod from an earlier run is still installed when S2 measures its baseline.** Expected: every `SatisMod*`
   plugin is removed before any server start. Pinned in Task 9 (`removes every spike mod before the baseline`).
4. **Something else POSTs to the echo server, or the right body arrives on the wrong path.** Expected: S1 passes only on
   the exact path, body and content type. Pinned in Task 8 (`S1 fails on the wrong path`).
5. **Someone adds a `pull_request` trigger to `spike.yml`.** Expected: CI fails before a fork's code can reach the PC.
   Pinned in Task 10 (the workflow guard test).

```ts
import { readFileSync } from "node:fs";
import { z } from "zod";

export const ToolchainSchema = z.strictObject({
  engine: z.string().min(1),
  sml: z.string().min(1),
  source: z.string().min(1),
});
export type Toolchain = z.infer<typeof ToolchainSchema>;

export function loadToolchain(path: string): Toolchain {
  return ToolchainSchema.parse(JSON.parse(readFileSync(path, "utf8")));
}

/** Each difference between the pinned toolchain and what the runner declares installed. Empty means they match. */
export function toolchainMismatches(required: Toolchain, installed: { engine: string; sml: string }): string[] {
  const out: string[] = [];
  if (installed.engine !== required.engine) out.push(`engine: required ${required.engine}, installed ${installed.engine}`);
  if (installed.sml !== required.sml) out.push(`sml: required ${required.sml}, installed ${installed.sml}`);
  return out;
}
```

`harness/src/config.ts`:

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { z } from "zod";

export const LOOPBACK_HOSTS = new Set(["127.0.0.1", "localhost", "[::1]"]);

const isLoopbackHttps = (value: string) => {
  const url = new URL(value);
  return url.protocol === "https:" && LOOPBACK_HOSTS.has(url.hostname);
};

/**
 * The runner's own config, kept outside the repository (the path is in SATIS_HARNESS_CONFIG). It holds every value no
 * captured source states: the test server's ports (in serverArgs), the Alpakit build command and its output folder.
 */
export const RunnerConfigSchema = z.strictObject({
  serverDir: z.string().min(1),
  serverExe: z.string().min(1).default("FactoryServer.exe"),
  apiBaseUrl: z.string().refine(isLoopbackHttps, "apiBaseUrl must be https on loopback (127.0.0.1, localhost or [::1])"),
  serverArgs: z.array(z.string()).default([]),
  logPath: z.string().min(1).optional(),
  buildCommand: z
    .array(z.string().min(1))
    .min(1, "buildCommand is empty: fill it from the captured Alpakit page (G2-prep)"),
  builtPluginDir: z.string().includes("{spike}"),
  installed: z.strictObject({ engine: z.string().min(1), sml: z.string().min(1) }),
});
export type RunnerConfig = z.infer<typeof RunnerConfigSchema>;

export function loadConfig(path: string): RunnerConfig {
  return RunnerConfigSchema.parse(JSON.parse(readFileSync(path, "utf8")));
}

/** sml-dedicated-servers-2026-09-27.adoc (FAQ, "Log Files"): a dedicated server's log "could" be here; S0 verifies it. */
export function logPathOf(cfg: RunnerConfig): string {
  return cfg.logPath ?? join(cfg.serverDir, "FactoryGame", "Saved", "Logs", "FactoryGame.log");
}

export function pluginDirFor(cfg: RunnerConfig, spike: string): string {
  return cfg.builtPluginDir.replaceAll("{spike}", spike);
}
```

"refuses" tests still pass. If it surfaces as a raw `TypeError` instead, wrap the body in `try { ... } catch { return false; }`.

```ts
import { readdirSync, readFileSync } from "node:fs";
import { basename, join } from "node:path";

export type UseKind = "include" | "symbol" | "method" | "module";
export interface Use { kind: UseKind; name: string; path: string; line: number }
export interface SourceFile { path: string; text: string }

const CODE_EXT = /\.(h|hpp|cpp)$/;

/** Blanks comments (and, if asked, string and char literals), keeping every newline so line numbers still match. */
function blank(text: string, strings: boolean): string {
  let out = "";
  let i = 0;
  const spaces = (chunk: string) => chunk.replace(/[^\n]/g, " ");
  while (i < text.length) {
    const c = text[i]!;
    const n = text[i + 1];
    if (c === "/" && (n === "/" || n === "*")) {
      const end = n === "/" ? text.indexOf("\n", i) : text.indexOf("*/", i + 2);
      const stop = end === -1 ? text.length : n === "/" ? end : end + 2;
      out += spaces(text.slice(i, stop));
      i = stop;
      continue;
    }
    if (c === '"' || c === "'") {
      let j = i + 1;
      while (j < text.length && text[j] !== c && text[j] !== "\n") j += text[j] === "\\" ? 2 : 1;
      const stop = Math.min(j + 1, text.length);
      out += strings ? spaces(text.slice(i, stop)) : text.slice(i, stop);
      i = stop;
      continue;
    }
    out += c;
    i++;
  }
  return out;
}

const lineAt = (text: string, index: number) => text.slice(0, index).split("\n").length;
const spikeOf = (path: string) => path.split("/").slice(0, 2).join("/");

interface Locals { types: Set<string>; methods: Set<string>; defines: Set<string>; headers: Set<string> }

function localsOf(files: SourceFile[]): Locals {
  const locals: Locals = { types: new Set(), methods: new Set(), defines: new Set(), headers: new Set() };
  for (const f of files) {
    if (/\.(h|hpp)$/.test(f.path)) locals.headers.add(basename(f.path));
    if (!CODE_EXT.test(f.path)) continue;
    const code = blank(f.text, true);
    // A definition (followed by ':' or '{'), not a forward declaration.
    for (const m of code.matchAll(/\b(?:class|struct|enum(?:\s+class)?)\s+(?:[A-Z0-9_]+_API\s+)?([A-Za-z_]\w*)\s*(?:final\s*)?[:{]/g)) {
      locals.types.add(m[1]!);
    }
    for (const m of code.matchAll(/^\s*#\s*define\s+([A-Za-z_]\w*)/gm)) locals.defines.add(m[1]!);
  }
  for (const f of files) {
    if (!CODE_EXT.test(f.path)) continue;
    for (const m of blank(f.text, true).matchAll(/\b([A-Z]\w*)::(~?[A-Za-z_]\w*)\s*\(/g)) {
      if (locals.types.has(m[1]!)) locals.methods.add(m[2]!);
    }
  }
  return locals;
}

function usesInCode(f: SourceFile, locals: Locals): Use[] {
  const uses: Use[] = [];
  const add = (kind: UseKind, name: string, line: number) => uses.push({ kind, name, path: f.path, line });
  blank(f.text, false).split("\n").forEach((raw, i) => {
    const m = /^\s*#\s*include\s*[<"]([^>"]+)[>"]/.exec(raw);
    if (!m) return;
    const inc = m[1]!;
    if (inc.endsWith(".generated.h") || locals.headers.has(basename(inc))) return;
    add("include", inc, i + 1);
  });
  blank(f.text, true).split("\n").forEach((line, i) => {
    if (/^\s*#\s*(include|define|pragma)/.test(line)) return;
    for (const m of line.matchAll(/\b([A-Z]\w*)::(~?[A-Za-z_]\w*)/g)) {
      if (!locals.types.has(m[1]!)) add("symbol", `${m[1]}::${m[2]}`, i + 1);
    }
    for (const m of line.matchAll(/(?:->|\.)\s*([A-Z]\w*)\s*\(/g)) {
      if (!locals.methods.has(m[1]!)) add("method", m[1]!, i + 1);
    }
    for (const m of line.matchAll(/\b([A-Z][A-Z0-9_]{2,})\s*\(/g)) {
      if (!locals.defines.has(m[1]!)) add("symbol", m[1]!, i + 1);
    }
    for (const m of line.matchAll(/(?<![\w:>.])([UAFIET][A-Z][A-Za-z0-9_]*)\b(?!\s*::)/g)) {
      const name = m[1]!;
      if (/^[A-Z0-9_]+$/.test(name) || locals.types.has(name)) continue;
      add("symbol", name, i + 1);
    }
  });
  return uses;
}

function modulesInBuildCs(f: SourceFile): Use[] {
  const text = blank(f.text, false);
  const uses: Use[] = [];
  const addStrings = (block: string, offset: number) => {
    for (const s of block.matchAll(/"([^"]+)"/g)) {
      uses.push({ kind: "module", name: `module:${s[1]}`, path: f.path, line: lineAt(text, offset + s.index!) });
    }
  };
  for (const m of text.matchAll(/DependencyModuleNames\s*\.\s*AddRange\s*\(\s*new\s+string\s*\[\s*\]\s*\{([^}]*)\}/g)) {
    addStrings(m[1]!, m.index! + m[0].indexOf(m[1]!));
  }
  for (const m of text.matchAll(/DependencyModuleNames\s*\.\s*Add\s*\(\s*("[^"]+")\s*\)/g)) {
    addStrings(m[1]!, m.index! + m[0].indexOf(m[1]!));
  }
  return uses;
}

/** Every external include, symbol, method and module dependency the spike sources use, deduplicated per line. */
export function extractUses(files: SourceFile[]): Use[] {
  const bySpike = new Map<string, SourceFile[]>();
  for (const f of files) bySpike.set(spikeOf(f.path), [...(bySpike.get(spikeOf(f.path)) ?? []), f]);
  const uses: Use[] = [];
  for (const group of bySpike.values()) {
    const locals = localsOf(group);
    for (const f of group) {
      if (f.path.endsWith(".Build.cs")) uses.push(...modulesInBuildCs(f));
      else if (CODE_EXT.test(f.path)) uses.push(...usesInCode(f, locals));
    }
  }
  const seen = new Set<string>();
  return uses.filter((u) => {
    const key = `${u.kind}|${u.name}|${u.path}|${u.line}`;
    return seen.has(key) ? false : (seen.add(key), true);
  });
}

export function parseSourceMap(md: string): { rows: Map<string, { header: string; source: string }>; badRows: string[] } {
  const rows = new Map<string, { header: string; source: string }>();
  const badRows: string[] = [];
  md.split(/\r?\n/).forEach((line, i) => {
    if (!line.trim().startsWith("|") || /^\|\s*-/.test(line.trim())) return;
    const cells = line.split("|").slice(1, -1).map((c) => c.trim().replace(/^`|`$/g, ""));
    if (cells[0] === "Symbol") return;
    const [symbol = "", header = "", source = ""] = cells;
    const where = `api-sources.md line ${i + 1}`;
    if (cells.length !== 3 || !symbol) return void badRows.push(`${where}: expected | Symbol | Header | Source |`);
    if (!/^\S+:\d+$/.test(header)) return void badRows.push(`${where}: header must be path:line, got "${header}"`);
    if (!source) return void badRows.push(`${where}: source is empty`);
    if (rows.has(symbol)) return void badRows.push(`${where}: duplicate row for ${symbol}`);
    rows.set(symbol, { header, source });
  });
  return { rows, badRows };
}

export function checkApi(files: SourceFile[], md: string): { missing: Use[]; badRows: string[] } {
  const { rows, badRows } = parseSourceMap(md);
  const keys = [...rows.keys()];
  const covered = (u: Use) => (u.kind === "method" ? keys.some((k) => k.endsWith(`::${u.name}`)) : rows.has(u.name));
  return { missing: extractUses(files).filter((u) => !covered(u)), badRows };
}

export function scanSpikes(repoRoot: string): SourceFile[] {
  const dir = join(repoRoot, "spikes");
  return readdirSync(dir, { recursive: true, encoding: "utf8" })
    .map((p) => p.replaceAll("\\", "/"))
    .filter((p) => CODE_EXT.test(p) || p.endsWith(".Build.cs"))
    .sort()
    .map((p) => ({ path: `spikes/${p}`, text: readFileSync(join(dir, p), "utf8") }));
}
```

```ts
import { createHash } from "node:crypto";
import { existsSync, readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { z } from "zod";

export const CONTRACT_REPO = "Sour-Dev-Home/satisfactory-dash";
export const CONTRACT_DIR = "packages/shared/src";
export const CONTRACT_ENTRY = "agent.ts";

export const ManifestSchema = z.strictObject({
  repo: z.string(),
  dir: z.string(),
  commit: z.string().regex(/^[0-9a-f]{40}$/),
  files: z.record(z.string(), z.string().regex(/^[0-9a-f]{64}$/)),
});
export type Manifest = z.infer<typeof ManifestSchema>;

export const sha256 = (text: string) => createHash("sha256").update(text, "utf8").digest("hex");

/** The same-folder modules a file imports, as file names ("./envelope" -> "envelope.ts"). */
export function relativeImports(text: string): string[] {
  const out = new Set<string>();
  for (const m of text.matchAll(/from\s+"\.\/([\w-]+)(?:\.(?:js|ts))?"/g)) out.add(`${m[1]}.ts`);
  return [...out].sort();
}

export async function vendorContract(
  commit: string,
  fetchFile: (path: string, commit: string) => Promise<string>,
): Promise<{ files: Record<string, string>; manifest: Manifest }> {
  const files: Record<string, string> = {};
  const queue = [CONTRACT_ENTRY];
  while (queue.length > 0) {
    const name = queue.shift()!;
    if (name in files) continue;
    const text = await fetchFile(`${CONTRACT_DIR}/${name}`, commit);
    if (/from\s+"\.\.\//.test(text)) throw new Error(`${name} imports from outside ${CONTRACT_DIR}`);
    files[name] = text;
    queue.push(...relativeImports(text).filter((f) => !(f in files)));
  }
  const hashes = Object.fromEntries(Object.keys(files).sort().map((f) => [f, sha256(files[f]!)]));
  return { files, manifest: ManifestSchema.parse({ repo: CONTRACT_REPO, dir: CONTRACT_DIR, commit, files: hashes }) };
}

/** Problems with the vendored copy in dir (manifest.json + src/). Empty means it is exactly the pinned commit's files. */
export function verifyContract(dir: string): string[] {
  const manifest = ManifestSchema.parse(JSON.parse(readFileSync(join(dir, "manifest.json"), "utf8")));
  const problems: string[] = [];
  for (const [name, hash] of Object.entries(manifest.files)) {
    const path = join(dir, "src", name);
    if (!existsSync(path)) {
      problems.push(`${name}: missing`);
      continue;
    }
    const text = readFileSync(path, "utf8");
    if (sha256(text) !== hash) problems.push(`${name}: changed since ${manifest.commit.slice(0, 7)}`);
    for (const dep of relativeImports(text)) {
      if (!(dep in manifest.files)) problems.push(`${name}: imports ${dep}, which is not vendored`);
    }
  }
  for (const f of readdirSync(join(dir, "src"))) if (!(f in manifest.files)) problems.push(`${f}: not in the manifest`);
  return problems;
}
```

```ts
import { createServer } from "node:http";
import type { AddressInfo } from "node:net";

/** The fixed loopback port the spike mods post to (the spike contract in the plan's Global Constraints). */
export const ECHO_PORT = 18080;
export const ECHO_MAX_BODY = 1024 * 1024;

export interface CapturedRequest {
  at: string;
  method: string;
  path: string;
  headers: Record<string, string | string[] | undefined>;
  body: string;
  tooLarge: boolean;
}
export interface Echo { url: string; port: number; requests: CapturedRequest[]; close(): Promise<void> }

export function startEcho(port = ECHO_PORT, now: () => Date = () => new Date()): Promise<Echo> {
  const requests: CapturedRequest[] = [];
  const server = createServer((req, res) => {
    const chunks: Buffer[] = [];
    let size = 0;
    let tooLarge = false;
    req.on("data", (chunk: Buffer) => {
      size += chunk.length;
      if (size > ECHO_MAX_BODY) tooLarge = true;
      else chunks.push(chunk);
    });
    req.on("end", () => {
      requests.push({
        at: now().toISOString(),
        method: req.method ?? "",
        path: req.url ?? "",
        headers: { ...req.headers },
        body: tooLarge ? "" : Buffer.concat(chunks).toString("utf8"),
        tooLarge,
      });
      res.writeHead(tooLarge ? 413 : 200, { "content-type": "application/json" });
      res.end(tooLarge ? '{"ok":false}' : '{"ok":true}');
    });
  });
  return new Promise((resolve, reject) => {
    server.once("error", reject);
    server.listen(port, "127.0.0.1", () => {
      const bound = (server.address() as AddressInfo).port;
      resolve({
        url: `http://127.0.0.1:${bound}`,
        port: bound,
        requests,
        close: () =>
          new Promise<void>((done) => {
            server.closeAllConnections();
            server.close(() => done());
          }),
      });
    });
  });
}
```

```ts
import { closeSync, existsSync, openSync, readSync, statSync } from "node:fs";

/** Every line a spike mod writes starts with this (the spike contract). */
export const MOD_PREFIX = "satis-mod";

export function logOffset(path: string): number {
  return existsSync(path) ? statSync(path).size : 0;
}

/** The text written after offset. A file smaller than offset was rotated, so it is read from the start. */
export function readLogSince(path: string, offset: number): string {
  if (!existsSync(path)) return "";
  const size = statSync(path).size;
  const from = size < offset ? 0 : offset;
  const length = size - from;
  if (length <= 0) return "";
  const buf = Buffer.alloc(length);
  const fd = openSync(path, "r");
  try {
    readSync(fd, buf, 0, length, from);
  } finally {
    closeSync(fd);
  }
  return buf.toString("utf8");
}

export interface WaitOptions {
  fromOffset: number;
  timeoutMs: number;
  pollMs?: number;
  sleep?: (ms: number) => Promise<void>;
  now?: () => number;
}

/** Resolves with the first line written after fromOffset that matches pattern, or rejects at the timeout. */
export async function waitForLine(path: string, pattern: RegExp, opts: WaitOptions): Promise<{ line: string }> {
  if (pattern.global || pattern.sticky) throw new Error("waitForLine needs a non-global, non-sticky pattern");
  const sleep = opts.sleep ?? ((ms: number) => new Promise<void>((r) => setTimeout(r, ms)));
  const now = opts.now ?? Date.now;
  const deadline = now() + opts.timeoutMs;
  for (;;) {
    const line = readLogSince(path, opts.fromOffset).split(/\r?\n/).find((l) => pattern.test(l));
    if (line !== undefined) return { line };
    if (now() >= deadline) throw new Error(`timed out after ${opts.timeoutMs} ms waiting for ${pattern} in ${path}`);
    await sleep(opts.pollMs ?? 1000);
  }
}

export function modLines(text: string): string[] {
  return text.split(/\r?\n/).filter((l) => l.includes(MOD_PREFIX));
}

/** Lines that look like version information, kept verbatim. Their real format is first seen in S0's evidence. */
export function versionLines(text: string, max = 20): string[] {
  return text.split(/\r?\n/).filter((l) => /version|changelist|\bCL\b/i.test(l)).slice(0, max);
}
```

```ts
import { request } from "node:https";
import { LOOPBACK_HOSTS } from "./config";

export type Transport = (url: URL, body: string) => Promise<{ status: number; text: string }>;

/**
 * POSTs JSON over HTTPS. The dedicated server's certificate is self-signed by default (dedicated-server-api.md, E3), so
 * verification is off. That is acceptable only because createServerApi allows loopback hosts alone.
 */
export const httpsLoopback: Transport = (url, body) =>
  new Promise((resolve, reject) => {
    const req = request(
      url,
      {
        method: "POST",
        rejectUnauthorized: false,
        timeout: 10_000,
        headers: { "content-type": "application/json", "content-length": Buffer.byteLength(body) },
      },
      (res) => {
        let text = "";
        res.setEncoding("utf8");
        res.on("data", (chunk: string) => (text += chunk));
        res.on("end", () => resolve({ status: res.statusCode ?? 0, text }));
      },
    );
    req.on("timeout", () => req.destroy(new Error("request timed out")));
    req.on("error", reject);
    req.end(body);
  });

export interface ServerApi { call(fn: string): Promise<{ status: number; body: unknown }> }

/** The dedicated server HTTPS API: POST /api/v1 with {"function": name} (captured QueryServerState requests). */
export function createServerApi(baseUrl: string, transport: Transport = httpsLoopback): ServerApi {
  const url = new URL("/api/v1", baseUrl);
  if (url.protocol !== "https:" || !LOOPBACK_HOSTS.has(url.hostname)) {
    throw new Error(`refusing a non-loopback server API: ${baseUrl}`);
  }
  return {
    async call(fn) {
      const { status, text } = await transport(url, JSON.stringify({ function: fn }));
      if (!text) return { status, body: null };
      try {
        return { status, body: JSON.parse(text) as unknown };
      } catch {
        return { status, body: text };
      }
    },
  };
}
```

```ts
import { z } from "zod";
import type { ServerApi } from "./server-api";

/** 20 minutes per window: the owner's decision of 2026-10-19 (the claims table said 30). */
export const TICK_WINDOW_MS = 20 * 60_000;
export const TICK_INTERVAL_MS = 10_000;

// The field the satisfactory-dash tick-rate card reads (game-adapter rawSchemas.ts, captured QueryServerState).
const QueryServerStateSchema = z.object({
  data: z.object({ serverGameState: z.object({ averageTickRate: z.number().nonnegative() }) }),
});

export async function readTickRate(api: ServerApi): Promise<number> {
  const { status, body } = await api.call("QueryServerState");
  if (status !== 200) throw new Error(`QueryServerState returned ${status}`);
  return QueryServerStateSchema.parse(body).data.serverGameState.averageTickRate;
}

export interface TickSeries { samples: { at: string; value: number }[]; errors: number; median: number | null }

export function median(values: number[]): number | null {
  if (values.length === 0) return null;
  const s = [...values].sort((a, b) => a - b);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 ? s[mid]! : (s[mid - 1]! + s[mid]!) / 2;
}

export async function sampleTicks(
  read: () => Promise<number>,
  opts: { durationMs: number; intervalMs: number; sleep: (ms: number) => Promise<void>; now: () => number },
): Promise<TickSeries> {
  const samples: { at: string; value: number }[] = [];
  let errors = 0;
  const end = opts.now() + opts.durationMs;
  while (opts.now() < end) {
    const at = new Date(opts.now()).toISOString();
    try {
      samples.push({ at, value: await read() });
    } catch {
      errors++;
    }
    await opts.sleep(opts.intervalMs);
  }
  return { samples, errors, median: median(samples.map((s) => s.value)) };
}
```

```ts
export function removeMod(name: string, serverDir: string): void {
  for (const gameFeature of [false, true]) rmSync(modTarget(serverDir, name, gameFeature), { recursive: true, force: true });

/** Copies a built plugin into the test server, replacing any earlier copy. Returns the plugin's name. */
export function installMod(pluginDir: string, serverDir: string): string {
  const uplugins = readdirSync(pluginDir).filter((f) => f.endsWith(".uplugin"));
  if (uplugins.length !== 1) throw new Error(`expected exactly one .uplugin in ${pluginDir}, found ${uplugins.length}`);
  const file = uplugins[0]!;
  const name = basename(file, ".uplugin");
  const meta = JSON.parse(readFileSync(join(pluginDir, file), "utf8").replace(/^\uFEFF/, "")) as { GameFeature?: unknown };
  removeMod(name, serverDir);
  const target = modTarget(serverDir, name, meta.GameFeature === true);
  mkdirSync(target, { recursive: true });
  cpSync(pluginDir, target, { recursive: true });
  return name;

export interface ServerProcess { pid: number; exited: Promise<number | null> }
export type Spawner = (exe: string, args: string[], cwd: string) => ServerProcess;
export type Killer = (pid: number) => Promise<void>;

export const spawnServer: Spawner = (exe, args, cwd) => {
  const child = spawn(exe, args, { cwd, stdio: "ignore", windowsHide: true });
  const exited = new Promise<number | null>((resolve) => {
    child.once("exit", (code) => resolve(code));
    child.once("error", () => resolve(null));
  });
  if (child.pid === undefined) throw new Error(`could not start ${exe}`);
  return { pid: child.pid, exited };
};

/** Ends the process and its children by pid only, never by image name, so another server is never touched. */
export const killTree: Killer = (pid) =>
  new Promise((resolve) => execFile("taskkill", ["/PID", String(pid), "/T", "/F"], () => resolve()));

export function startServer(
  cfg: Pick<RunnerConfig, "serverDir" | "serverExe" | "serverArgs">,
  spawner: Spawner = spawnServer,
): ServerProcess {
  return spawner(join(cfg.serverDir, cfg.serverExe), ["-log", INSECURE_LOCAL_ARG, ...cfg.serverArgs], cfg.serverDir);
}

const realSleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));

/** HealthCheck needs no authentication (dedicated-server-api.md); any 200 means the API is up. */
export async function waitHealthy(
  api: ServerApi,
  opts: { timeoutMs: number; pollMs?: number; sleep?: (ms: number) => Promise<void>; now?: () => number },
): Promise<unknown> {
  const sleep = opts.sleep ?? realSleep;
  const now = opts.now ?? Date.now;
  const deadline = now() + opts.timeoutMs;
  for (;;) {
    try {
      const { status, body } = await api.call("HealthCheck");
      if (status === 200) return body;
    } catch {
      // not listening yet
    }
    if (now() >= deadline) throw new Error(`server not healthy after ${opts.timeoutMs} ms`);
    await sleep(opts.pollMs ?? 2000);
  }
}

/** Asks the server to shut down (the API's Shutdown function), then kills the spawned pid if it outlives graceMs. */
export async function stopServer(
  proc: ServerProcess,
  api: ServerApi,
  opts: { graceMs: number; kill: Killer; sleep?: (ms: number) => Promise<void> },
): Promise<"exited" | "killed"> {
  try {
    await api.call("Shutdown");
  } catch {
    // already down, or not up yet
  }
  const sleep = opts.sleep ?? realSleep;
  const outcome = await Promise.race([proc.exited.then(() => "exited" as const), sleep(opts.graceMs).then(() => "timeout" as const)]);
  if (outcome === "exited") return "exited";
  await opts.kill(proc.pid);
  return "killed";
}
```

```ts
import type { Evidence, Verdict } from "../../harness/src/verdict";

export const claim = "C4";
export const S2_PATH = "/s2";
export const S2_EXPECTED_POSTS = 40;
/** "No drop" means the with-mod median is at least 95% of the baseline median. */
export const S2_TICK_TOLERANCE = 0.05;

export function evaluate(e: Evidence): Verdict {
  const reasons: string[] = [];
  const ns = e.echo
    .filter((r) => r.method === "POST" && r.path === S2_PATH)
    .map((r) => {
      try {
        return (JSON.parse(r.body) as { n?: unknown }).n;
      } catch {
        return undefined;
      }
    });
  if (ns.length !== S2_EXPECTED_POSTS) reasons.push(`expected ${S2_EXPECTED_POSTS} posts to ${S2_PATH}, got ${ns.length}`);
  else if (!ns.every((n, i) => n === i + 1)) reasons.push(`the posts' n values are not 1..${S2_EXPECTED_POSTS} in order`);
  const base = e.ticks?.baseline.median ?? null;
  const withMod = e.ticks?.withMod.median ?? null;
  if (base === null || withMod === null) reasons.push("a tick-rate window has no samples");
  else if (withMod < base * (1 - S2_TICK_TOLERANCE)) {
    reasons.push(`tick median dropped from ${base} to ${withMod}, more than ${S2_TICK_TOLERANCE * 100}%`);
  }
  return reasons.length
    ? { pass: false, reasons }
    : { pass: true, reasons: [`${S2_EXPECTED_POSTS} posts in order; tick median ${base} without the mod, ${withMod} with it`] };
```

```ts
  reasons: z.array(z.string()).min(1),
  startedAt: z.iso.datetime(),
  endedAt: z.iso.datetime(),

  modLines: z.array(z.string()),

});

/** Home-directory paths name the machine's user. Bundles are public artifacts, so they never carry one. */
export function redact(text: string): string {
  // A separator is a slash, a backslash, or the escaped backslash JSON writes ("\\").
  return text
    .replace(/[A-Za-z]:(?:\\{1,2}|\/)Users(?:\\{1,2}|\/)[^\\/\s"]+/g, "<home>")
    .replace(/\/(?:home|Users)\/[^/\s"]+/g, "<home>");
}

export function writeEvidence(dir: string, result: Result, captures: Record<string, unknown>): string {
  const parsed = ResultSchema.parse(JSON.parse(redact(JSON.stringify(result))));
  const out = join(dir, `${parsed.spike}-${parsed.startedAt.replace(/[:.]/g, "-")}`);
  mkdirSync(out, { recursive: true });
  for (const name of Object.keys(captures)) {
    if (!/^[\w.-]+$/.test(name) || name.startsWith(".")) throw new Error(`bad capture name: ${name}`);
  }
  writeFileSync(join(out, "result.json"), `${JSON.stringify(parsed, null, 2)}\n`);
  for (const [name, value] of Object.entries(captures)) {
    const text = typeof value === "string" ? value : `${JSON.stringify(value, null, 2)}\n`;
    writeFileSync(join(out, name), redact(text));
  }
  return out;
}
```

```ts
const message = (e: unknown) => (e instanceof Error ? e.message : String(e));

export async function runSpike(spike: SpikeId, deps: RunDeps): Promise<{ result: Result; dir: string }> {
  const spec = SPIKES[spike];
  const mismatches = toolchainMismatches(deps.toolchain, deps.config.installed);
  if (mismatches.length) throw new RefusalError(`toolchain mismatch: ${mismatches.join("; ")}`);
  const api = deps.checkApi();
  if (api.missing.length || api.badRows.length) {
    const list = [...api.badRows, ...api.missing.map((u) => `${u.path}:${u.line} ${u.name}`)];
    throw new RefusalError(`check-api failed: ${list.join(", ")}`);
  }

  const startedAt = deps.now().toISOString();
  await deps.build(spike);
  for (const id of SPIKE_IDS) deps.remove(modName(id));

  const runReasons: string[] = [];
  let baseline: TickSeries | undefined;
  let withMod: TickSeries | undefined;
  let logText = "";
  let echo: Echo | undefined;

  if (spec.ticks) {
    const proc = deps.start();
    try {
      await deps.waitHealthy();
      baseline = await deps.sampleTicks();
    } catch (e) {
      runReasons.push(`baseline: ${message(e)}`);
    } finally {
      await deps.stop(proc);
    }
  }

  const installed = deps.install(pluginDirFor(deps.config, spike));
  if (installed !== modName(spike)) throw new RefusalError(`the built plugin is ${installed}, expected ${modName(spike)}`);

  try {
    if (spec.echo) echo = await deps.startEcho();
    const offset = deps.logOffset();
    const proc = deps.start();
    try {
      await deps.waitHealthy();
      await deps.waitForLine(spec.doneLine, offset, DONE_TIMEOUT_MS);
      if (spec.ticks) withMod = await deps.sampleTicks();
      if (spec.finalLine) await deps.waitForLine(spec.finalLine, offset, FINAL_TIMEOUT_MS);
    } catch (e) {
      runReasons.push(message(e));
    } finally {
      await deps.stop(proc);
      logText = deps.readLogSince(offset);
    }
  } finally {
    await echo?.close();
  }

  const evidence: Evidence = {
    modLines: modLines(logText),
    echo: echo?.requests ?? [],
    ...(baseline && withMod ? { ticks: { baseline, withMod } } : {}),
  };
  const verdict = spec.evaluate(evidence);
  const result: Result = {
    spike,
    claim: spec.claim,
    pass: runReasons.length === 0 && verdict.pass,
    reasons: [...runReasons, ...verdict.reasons],
    startedAt,
    endedAt: deps.now().toISOString(),
    toolchain: {
      required: { engine: deps.toolchain.engine, sml: deps.toolchain.sml },
      declared: deps.config.installed,
    },
    versionLines: versionLines(logText),
    modLines: evidence.modLines,
    harnessCommit: deps.env.commit,
    runUrl: deps.env.runUrl,
  };
  const captures: Record<string, unknown> = {};
  if (spec.echo) captures["echo.json"] = evidence.echo;
  if (spec.ticks) captures["ticks.json"] = { baseline: baseline ?? null, withMod: withMod ?? null };
  // The full server log stays on the runner: it can name the machine, and bundles are public artifacts.
  return { result, dir: writeEvidence(deps.outDir, result, captures) };
}

const sleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));

export function realDeps(config: RunnerConfig, toolchain: Toolchain, outDir: string, repoRoot: string): RunDeps {
  const api = createServerApi(config.apiBaseUrl);
  const logPath = logPathOf(config);
  return {
    config,
    toolchain,
    outDir,
    checkApi: () => checkApi(scanSpikes(repoRoot), readFileSync(join(repoRoot, "api-sources.md"), "utf8")),
    build: (spike) =>
      new Promise((resolve, reject) => {
        const [exe, ...args] = config.buildCommand.map((a) => a.replaceAll("{spike}", spike));
        execFile(exe!, args, { cwd: repoRoot, maxBuffer: 64 * 1024 * 1024 }, (err) => (err ? reject(new Error(`build failed: ${err.message}`)) : resolve()));
      }),
    remove: (name) => removeMod(name, config.serverDir),
    install: (pluginDir) => installMod(pluginDir, config.serverDir),
    start: () => startServer(config),
    stop: async (proc) => void (await stopServer(proc, api, { graceMs: 60_000, kill: killTree })),
    waitHealthy: async () => void (await waitHealthy(api, { timeoutMs: 10 * MIN })),
    logOffset: () => logOffset(logPath),
    waitForLine: async (pattern, fromOffset, timeoutMs) => void (await waitForLine(logPath, pattern, { fromOffset, timeoutMs })),
    readLogSince: (offset) => readLogSince(logPath, offset),
    startEcho: () => startEcho(),
    sampleTicks: () => sampleTicks(() => readTickRate(api), { durationMs: TICK_WINDOW_MS, intervalMs: TICK_INTERVAL_MS, sleep, now: Date.now }),

    },
  };
}
```
