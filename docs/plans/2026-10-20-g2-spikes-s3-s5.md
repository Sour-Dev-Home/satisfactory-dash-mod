# G2 spikes S4, S5 and S3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three spikes that settle claims C6 (a credential in the mod's config), C7 (enrol and push a snapshot to a local backend) and C5 (a power reading that matches FRM). Each produces a harness-written PASS or FAIL bundle.

**Architecture:** Each spike is a small C++ SML plugin under `spikes/S#/`, built by `scripts/build-spike.ps1`, plus harness support in `harness/src/` with unit tests. The harness writes the mod's SML config file before the boot (S4, S5), runs a throwaway satisfactory-dash stack through compose plus a loopback relay (S5), and pairs the mod's power lines with FRM's `getPower` (S3).

**Tech Stack:** UE 5.6.1-CSS C++ (SML 3.12.0 at `8eebc9e`), Node/TypeScript harness (vitest, zod), Docker Desktop compose, satisfactory-dash pinned at `b11c23b570ce16e0fad8157f2522c7dc78528591`.

**Spec:** `docs/specs/2026-10-20-g2-spikes-s3-s5-design.md` (owner-approved 2026-10-20, PR #12), which extends `docs/specs/2026-10-19-g2-harness-design.md`.

## Global Constraints

- **Order: S4, then S5, then S3.** S3's runner config and fixtures wait for satisfactory-dash #462.
- **No API from memory** (`CLAUDE.md`). Every engine, SML or FactoryGame symbol and every `#include` under `spikes/` has an `api-sources.md` row (symbol | `path:line` | source).
  - The rows below were read on 2026-10-20.
  - Run `check-api` after writing each plugin. For each use it lists, open the header, find the declaration, and add its row. Never delete code to get past the check.
- **Pinned satisfactory-dash commit:** `b11c23b570ce16e0fad8157f2522c7dc78528591` (main on 2026-10-20). Every satisfactory-dash file cited here is read at this commit.
- **The spike contract:**
  - Plugin names: `SatisModS3`, `SatisModS4`, `SatisModS5`.
  - Every spike logs `satis-mod loaded` at startup, through its own `LogSatisMod` category (the game filters `LogTemp` to Warning).
- **S5 runs only from a local session**, never on the GitHub runner (owner, 2026-10-20). `satis-runner` is not in `docker-users`.
- **No real credential is ever used.**
  - Every credential, code and secret is generated per run.
  - It's written only to the test server's `Configs` or to the throwaway database, and deleted afterwards.
  - It never appears in a log line the mod writes.
- **The test server stays on ports 17777/18888** (runner config). The real server can stay up.
- **A failed spike stops the sequence.** Report it with its bundle. Never change a pass condition to get past it.
- **Plain PRs to `main`**, one per spike, merged by the owner or on the owner's standing go-ahead. Commit and PR attribution as before.

**Rulings carried from the research (2026-10-20):**
1. **S4 logs a SHA-1 prefix, not the spec's SHA-256.** The engine's Core module has `FSHA1` (`Core/Public/Misc/SecureHash.h:313`, `HashBuffer` at `:375`) and no SHA-256. The harness computes the same SHA-1.
2. **S5 reaches the stack through a loopback relay** (owner's choice, 2026-10-20). satisfactory-dash's `compose.yaml` publishes no port by design (lines 8-11). A harness-owned override adds a `socat` relay in the backend's network namespace, as `cloudflared` does, published on `127.0.0.1` only.
3. **S5's "snapshot stored" check** is the snapshot route's `200`, plus `agents.agent_credentials.last_seen_at` being set. The route stamps it (`backend/src/modules/agents/repositories/agentRepository.ts:132`), and sends the data to in-memory ingest rather than one table.
4. **S5's secret-absence check** covers the code (the harness knows it) and the string `Bearer`. The agent secret is generated inside the backend and stored only as a SHA-256, so the harness can't search the log for it. The mod never logs it.
5. **S3 finds circuits with `FindCircuit<UFGPowerCircuit>(id)`**, scanning IDs 0 to 9999. The circuit map `mCircuits` is private (`FGCircuitSubsystem.h:248-251`); `FindCircuit<T>` is public (`:88`).
6. **S3 pairs FRM circuit groups that hold exactly one circuit** (`AssociatedCircuits` of length 1). FRM's IDs are the game's circuit IDs (capture `frm-getPower-2026-09-22-F-panel.json`). Multi-circuit groups are recorded, not judged.

## Review Focus

1. **The harness crashes, or the run times out, between writing a credential and deleting it.** Expected: the cfg file is gone after every run, including failed ones. Pinned in Task 1 (`removeModConfig` in a `finally`, with a test that a thrown `waitHealthy` still removes it).
2. **A compose stack is left running after a failed S5**, or a second run reuses the old database. Expected: `down -v` always runs, and every run starts fresh. Pinned in Task 3 (`down` in a `finally`; a test where `seedCode` throws still calls `down`).
3. **The S5 override or env ever names a non-loopback address.** Expected: the harness refuses before `compose up`. Pinned in Task 3 (`assertLoopbackOnly`, with a test rejecting `0.0.0.0` and a LAN address).
4. **FRM answers slowly or not at all during S3.** Expected: that reading pairs with `frm: null`, and the run fails with fewer than 10 pairs. It never pairs an old FRM reading. Pinned in Task 5 (a test where the FRM fetch throws).
5. **A circuit exists in FRM but not in the mod's lines, or the reverse.** Expected: FAIL, naming the circuit. Pinned in Task 5's `evaluate` tests.

```ts
import { createHash, randomBytes } from "node:crypto";
import { mkdirSync, rmSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";

/** SML's path: FPaths::ProjectDir() + "Configs/" + "<ModReference>.cfg" with no category (ConfigManager.cpp:309-318). */
export function modConfigPath(serverDir: string, modReference: string): string {
  return join(serverDir, "FactoryGame", "Configs", `${modReference}.cfg`);
}

/** A root section serialises as a JSON object keyed by property name (ConfigPropertySection.cpp:18-24). */
export function writeModConfig(serverDir: string, modReference: string, values: Record<string, string>): string {
  const path = modConfigPath(serverDir, modReference);
  mkdirSync(dirname(path), { recursive: true });
  writeFileSync(path, `${JSON.stringify(values, null, 2)}\n`);
  return path;
}

export function removeModConfig(serverDir: string, modReference: string): void {
  rmSync(modConfigPath(serverDir, modReference), { force: true });
}

const BASE32 = "ABCDEFGHIJKLMNOPQRSTUVWXYZ234567";
/** 32 base32 characters (160 bits); made fresh for every run and never reused. */
export function randomCredential(): string {
  return [...randomBytes(32)].map((b) => BASE32[b % 32]).join("");
}

/** The mod logs FSHAHash::ToString() lowercased and cut to 12 characters (SecureHash.h:242, :375). */
export const sha1Prefix = (value: string): string => createHash("sha1").update(value, "utf8").digest("hex").slice(0, 12);
```

- [ ] **Step 8: Write `spikes/S4/pass.ts`:**

```ts
// S4 (claim C6): the mod reads a credential from its SML config on the dedicated server and never logs it.
import type { Evidence, Verdict } from "../../harness/src/verdict";

export const claim = "C6";
const READ = /satis-mod s4 read length=(\d+) sha1=([0-9a-f]{12})/;

export function evaluate(e: Evidence): Verdict {
  if (!e.credential) return { pass: false, reasons: ["the harness wrote no credential"] };
  const m = e.modLines.map((l) => READ.exec(l)).find((x) => x !== null);
  if (!m) return { pass: false, reasons: ['no "satis-mod s4 read" line in this run\'s server log'] };
  if (e.credential.inLog) return { pass: false, reasons: ["the credential appears in the server log"] };
  const { length, sha1Prefix } = e.credential;
  if (Number(m[1]) !== length || m[2] !== sha1Prefix) {
    return { pass: false, reasons: [`the mod read a different value (length ${m[1]}, sha1 ${m[2]}; wrote length ${length}, sha1 ${sha1Prefix})`] };
  }
  return { pass: true, reasons: ["the mod read the credential the harness wrote, and the log never shows it"] };
}
```

```cpp
#include "SatisModS4.h"
#include "SatisModS4Config.h"
#include "Configuration/ConfigManager.h"
#include "Configuration/Properties/ConfigPropertySection.h"
#include "Configuration/Properties/ConfigPropertyString.h"
#include "Engine/GameInstance.h"
#include "Engine/World.h"
#include "Misc/SecureHash.h"

// Our own category: the game's config filters LogTemp to Warning ([Core.Log] LogTemp=all Warning).
DEFINE_LOG_CATEGORY_STATIC(LogSatisMod, Display, All);

void FSatisModS4Module::StartupModule()
{
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod loaded"));
	// UConfigManager is a game-instance subsystem (ConfigManager.h:44), so read once the first world has one.
	WorldInitHandle = FWorldDelegates::OnPostWorldInitialization.AddLambda([this](UWorld* World, const UWorld::InitializationValues)
	{
		ReadCredential(World);
	});
}

void FSatisModS4Module::ShutdownModule()
{
	FWorldDelegates::OnPostWorldInitialization.Remove(WorldInitHandle);
}

void FSatisModS4Module::ReadCredential(UWorld* World)
{
	if (bRead || World == nullptr || World->GetGameInstance() == nullptr) { return; }
	UConfigManager* Configs = World->GetGameInstance()->GetSubsystem<UConfigManager>();
	if (Configs == nullptr) { return; }
	bRead = true;
	Configs->RegisterModConfiguration(USatisModS4Config::StaticClass()); // loads the file from disk (ConfigManager.cpp:287)
	UConfigPropertySection* Root = Configs->GetConfigurationRootSection(GetDefault<USatisModS4Config>()->ConfigId);
	UConfigPropertyString* Property = Root ? Cast<UConfigPropertyString>(Root->SectionProperties.FindRef(TEXT("credential"))) : nullptr;
	if (Property == nullptr)
	{
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s4 error=no-credential-property"));
		return;
	}
	// The value itself is never logged: only its length and a SHA-1 prefix the harness can check.
	const FTCHARToUTF8 Utf8(*Property->Value);
	const FString Prefix = FSHA1::HashBuffer(Utf8.Get(), Utf8.Length()).ToString().Left(12).ToLower();
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod s4 read length=%d sha1=%s"), Property->Value.Len(), *Prefix);
}

IMPLEMENT_MODULE(FSatisModS4Module, SatisModS4)
```

```ts
// S5 (claim C7): the mod enrols with a one-time code and pushes one valid snapshot to a throwaway local backend.
import type { Evidence, Verdict } from "../../harness/src/verdict";
export { S5_AGENT_VERSION, s5SnapshotBody } from "./body";
import { S5_AGENT_VERSION } from "./body";

export const claim = "C7";
const LINE = /satis-mod s5 enroll=(-?\d+) snapshot=(-?\d+)/;

export function evaluate(e: Evidence): Verdict {
  const m = e.modLines.map((l) => LINE.exec(l)).find((x) => x !== null);
  if (!m) return { pass: false, reasons: ['no "satis-mod s5" line in this run\'s server log'] };
  if (!e.backend) return { pass: false, reasons: ["the harness read no backend state"] };
  const b = e.backend;
  const reasons: string[] = [];
  if (m[1] !== "201") reasons.push(`enrolment answered ${m[1]}, not 201`);
  if (m[2] !== "200") reasons.push(`the snapshot answered ${m[2]}, not 200`);
  if (!b.codeConsumed) reasons.push("the database still shows the code unspent");
  if (b.agentVersion !== S5_AGENT_VERSION) reasons.push(`the credential's agent_version is ${b.agentVersion}, not ${S5_AGENT_VERSION}`);
  if (!b.lastSeen) reasons.push("last_seen_at was never set: no snapshot reached the agent route");
  if (b.codeInLog) reasons.push("the enrolment code appears in the server log");
  if (b.bearerInLog) reasons.push('"Bearer" appears in the server log');
  return reasons.length
    ? { pass: false, reasons }
    : { pass: true, reasons: ["the mod enrolled (201), its snapshot was accepted (200), and the database agrees"] };
}
```

```ts
const scryptAsync = promisify(scrypt) as (p: string, s: Buffer, k: number, o: object) => Promise<Buffer>;

/** Throwaway values for compose.yaml's required variables (compose.yaml:23-63). The hash is the backend's own format,
 *  scrypt$N$r$p$salt$hash with N=2^15, r=8, p=1, a 16-byte salt and a 64-byte key (passwordHash.ts:9, DEFAULT_PARAMS,
 *  KEY_LENGTH, SALT_BYTES); the session secret is 64 random base64 characters (authConfig.ts MIN_SECRET_LENGTH = 43). */
export async function composeEnv(): Promise<Record<string, string>> {
  const salt = randomBytes(16);
  const key = await scryptAsync(randomBytes(24).toString("base64"), salt, 64, { N: 2 ** 15, r: 8, p: 1, maxmem: 64 * 1024 * 1024 });
  const pw = () => randomBytes(24).toString("base64url");
  return {
    POSTGRES_PASSWORD: pw(),
    DB_MIGRATOR_PASSWORD: pw(),
    DB_APP_PASSWORD: pw(),
    DASHBOARD_ADMIN_USER: "spike",
    DASHBOARD_ADMIN_PASSWORD_HASH: ["scrypt", 32768, 8, 1, salt.toString("base64"), key.toString("base64")].join("$"),
    SESSION_SECRET: randomBytes(48).toString("base64"),
  };
}

/** Review Focus 3: every URL-looking value must point at loopback. */
export function assertLoopbackOnly(env: Record<string, string>): void {
  for (const [key, value] of Object.entries(env)) {
    for (const part of value.split(",")) {
      const v = part.trim();
      if (!/^https?:\/\//.test(v)) continue;
      if (!LOOPBACK_HOSTS.has(new URL(v).hostname)) throw new Error(`${key} is not loopback: S5's backend is local only`);
    }
  }
}

    return r.stdout;

  const up = await compose("up", "-d", "--wait");
  if (up.code !== 0) {
    await down();
```

```ts
import { z } from "zod";
import type { PowerPair, PowerReading } from "./verdict";

// Field names from satisfactory-dash raw-sources/captured-responses/frm-getPower-2026-09-22-*.json.
const GroupSchema = z.object({
  CircuitGroupID: z.number().int(),
  PowerProduction: z.number(),
  PowerConsumed: z.number(),
  PowerCapacity: z.number(),
  AssociatedCircuits: z.array(z.number().int()),
});
export interface FrmGroup { groupId: number; circuits: number[]; production: number; consumption: number; capacity: number }

export function parseGetPower(body: unknown): FrmGroup[] {
  return z.array(GroupSchema).parse(body).map((g) => ({
    groupId: g.CircuitGroupID, circuits: g.AssociatedCircuits, production: g.PowerProduction, consumption: g.PowerConsumed, capacity: g.PowerCapacity,
  }));
}

const LINE = /satis-mod s3 circuit=(\d+) production=([\d.]+) consumption=([\d.]+) capacity=([\d.]+)/;
export function parseS3Lines(lines: string[]): { circuitId: number; reading: PowerReading }[] {
  return lines.flatMap((l) => {
    const m = LINE.exec(l);
    return m ? [{ circuitId: Number(m[1]), reading: { production: Number(m[2]), consumption: Number(m[3]), capacity: Number(m[4]) } }] : [];
  });
}

/** A mod circuit pairs with the FRM group whose only associated circuit it is (ruling 6); otherwise frm is null. */
export function pairReadings(at: string, mod: { circuitId: number; reading: PowerReading }[], frm: FrmGroup[] | null): PowerPair[] {
  return mod.map(({ circuitId, reading }) => {
    const g = frm?.find((x) => x.circuits.length === 1 && x.circuits[0] === circuitId);
    return { at, circuitId, mod: reading, frm: g ? { production: g.production, consumption: g.consumption, capacity: g.capacity } : null };
  });
}

/** Polls the log for new s3 lines; for each non-empty batch, reads FRM at once and pairs the two (Review Focus 4: a
 *  failed FRM read pairs with null, never with an older reading). */
export async function collectPowerPairs(opts: {
  readNew: () => string[];
  frm: () => Promise<FrmGroup[]>;
  sleep: (ms: number) => Promise<void>;
  now: () => number;
  durationMs: number;
  intervalMs: number;
}): Promise<{ pairs: PowerPair[]; frmCircuits: number[]; modCircuits: number[] }> {
  const pairs: PowerPair[] = [];
  const frmCircuits = new Set<number>();
  const end = opts.now() + opts.durationMs;
  while (opts.now() < end) {
    const mod = parseS3Lines(opts.readNew());
    if (mod.length) {
      let frm: FrmGroup[] | null = null;
      try { frm = await opts.frm(); } catch { frm = null; }
      for (const g of frm ?? []) if (g.circuits.length === 1) frmCircuits.add(g.circuits[0]!);
      pairs.push(...pairReadings(new Date(opts.now()).toISOString(), mod, frm));
    }
    await opts.sleep(opts.intervalMs);
  }
  return { pairs, frmCircuits: [...frmCircuits], modCircuits: [...new Set(pairs.map((p) => p.circuitId))] };
}
```

```ts
import type { Evidence, Verdict } from "../../harness/src/verdict";

export const claim = "C5";
const NEED = 10;
const within = (a: number, b: number) => Math.abs(a - b) <= 0.01 * Math.max(Math.abs(a), Math.abs(b), 1);

export function evaluate(e: Evidence): Verdict {
  if (!e.power) return { pass: false, reasons: ["the harness collected no power readings"] };
  const reasons: string[] = [];
  for (const c of e.power.frmCircuits) if (!e.power.modCircuits.includes(c)) reasons.push(`FRM has circuit ${c}, but the mod never logged it`);
  for (const c of e.power.modCircuits) if (!e.power.frmCircuits.includes(c)) reasons.push(`the mod logged circuit ${c}, but FRM doesn't have it`);
  const judged = e.power.pairs.filter((p) => p.frm !== null);
  if (judged.length < NEED) reasons.push(`${judged.length} paired readings, need ${NEED}`);
  for (const p of judged) {
    if (!within(p.mod.production, p.frm!.production)) reasons.push(`${p.at} circuit ${p.circuitId}: production ${p.mod.production} vs FRM ${p.frm!.production}`);
    if (!within(p.mod.capacity, p.frm!.capacity)) reasons.push(`${p.at} circuit ${p.circuitId}: capacity ${p.mod.capacity} vs FRM ${p.frm!.capacity}`);
  }
  return reasons.length
    ? { pass: false, reasons }
    : { pass: true, reasons: [`${judged.length} readings: production and capacity within 1% of FRM, the same circuits on both sides`] };
}
```

`Private/SatisModS3.cpp`:

```cpp
#include "SatisModS3.h"
#include "Engine/World.h"
#include "FGCircuitSubsystem.h"
#include "FGPowerCircuit.h"

DEFINE_LOG_CATEGORY_STATIC(LogSatisMod, Display, All);

void FSatisModS3Module::StartupModule()
{
	UE_LOG(LogSatisMod, Display, TEXT("satis-mod loaded"));
	WorldInitHandle = FWorldDelegates::OnPostWorldInitialization.AddLambda([this](UWorld* InWorld, const UWorld::InitializationValues)
	{
		if (World.IsValid() || InWorld == nullptr || !InWorld->IsGameWorld()) { return; }
		World = InWorld;
		// AddTicker's delay is also its interval: "return true to fire after another InDelay time" (Ticker.h:56). So one
		// ticker waits 60 s for the save to load, logs once, and hands over to a second one that logs every 10 s.
		FirstHandle = FTSTicker::GetCoreTicker().AddTicker(TEXT("SatisModS3First"), 60.0f, [this](float)
		{
			LogCircuits();
			EveryHandle = FTSTicker::GetCoreTicker().AddTicker(TEXT("SatisModS3Every10s"), 10.0f, [this](float)
			{
				LogCircuits();
				return Logged < Total; // false after the 12th reading removes it
			});
			return false;
		});
	});
}

void FSatisModS3Module::ShutdownModule()
{
	FWorldDelegates::OnPostWorldInitialization.Remove(WorldInitHandle);
	FTSTicker::RemoveTicker(FirstHandle);
	FTSTicker::RemoveTicker(EveryHandle);
}

void FSatisModS3Module::LogCircuits()
{
	++Logged;
	AFGCircuitSubsystem* Circuits = World.IsValid() ? AFGCircuitSubsystem::GetCircuitSubsystem(World.Get()) : nullptr;
	if (Circuits == nullptr)
	{
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s3 error=no-circuit-subsystem"));
		return;
	}
	// mCircuits is private (FGCircuitSubsystem.h:248-251); FindCircuit<T> is public (:88). IDs are small ints (ruling 5).
	for (int32 Id = 0; Id < 10000; ++Id)
	{
		UFGPowerCircuit* Circuit = Circuits->FindCircuit<UFGPowerCircuit>(Id);
		if (Circuit == nullptr) { continue; }
		FPowerCircuitStats Stats;
		Circuit->GetStats(Stats);
		UE_LOG(LogSatisMod, Display, TEXT("satis-mod s3 circuit=%d production=%.2f consumption=%.2f capacity=%.2f"),
			Circuit->GetCircuitID(), Stats.PowerProduced, Stats.PowerConsumed, Stats.PowerProductionCapacity);
	}
}

IMPLEMENT_MODULE(FSatisModS3Module, SatisModS3)
```
