# G2 Spikes (S0–S2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four throwaway SML mods (S0, S1, S1b, S2), each testing one claim in `mod-claims.md` (C1–C4). Each is built by a scripted Alpakit `PackagePlugin` run, judged by the merged harness on the owner's test dedicated server, and leaves an evidence bundle.

**Architecture:** Each spike is a C++ library plugin `spikes/S#/SatisModS#/`, the shape of Alpakit's "C++ & Blueprint Library" template with one runtime module. `scripts/build-spike.ps1` mirrors a spike into the SML project's `Mods/` folder, runs Alpakit's UAT `PackagePlugin` command for a Windows Server, and unzips the archived plugin to `D:\satis-build\<S#>`. That folder is the harness's `builtPluginDir`. Every engine, SML or game symbol a spike uses has an `api-sources.md` row citing the installed header's `path:line`. `check-api` fails otherwise.

**Tech Stack:** C++20 on Unreal Engine 5.6.1-CSS (release css-83); SML 3.12.0 at SatisfactoryModLoader `8eebc9e` ("Update headers to CL513885"); PowerShell 7; the harness from #2 and #3.

**Spec:** `docs/specs/2026-10-19-g2-harness-design.md`; the harness plan `docs/plans/2026-10-19-g2-harness.md` ("the spike contract" in its Global Constraints).

## Review Focus

1. **The editor build or the dedicated-server cook fails for a C++-only plugin.** Expected: `build-spike.ps1` exits non-zero with UAT's log tail, and the harness records a refusal. - [ ] **Step 4: Write `scripts/build-spike.ps1`**

```powershell
# Builds one G2 spike for a Windows dedicated server with Alpakit's UAT PackagePlugin command, and unzips the
# archived plugin to -Out. Command line from Alpakit (Mods/Alpakit/Source/Alpakit/Private/AlpakitProfile.cpp:47-87)
# and SML's CI (.github/workflows/build.yml:192). Output location from PackagePlugin.cs:215-219.
param(
	[Parameter(Mandatory)] [ValidatePattern('^S[0-9][a-z]?$')] [string] $Spike,
	[Parameter(Mandatory)] [string] $Project,
	[Parameter(Mandatory)] [string] $Engine,
	[Parameter(Mandatory)] [string] $Out
)
$ErrorActionPreference = 'Stop'
$plugin = "SatisMod$Spike"
$repo = Split-Path $PSScriptRoot -Parent
$source = Join-Path $repo "spikes\$Spike\$plugin"
$uproject = Join-Path $Project 'FactoryGame.uproject'
if (-not (Test-Path "$source\$plugin.uplugin")) { throw "no spike plugin at $source" }
if (-not (Test-Path $uproject)) { throw "no SML project at $uproject" }

# Mirror the spike into the project's Mods folder; /MIR also deletes files removed from the source.
$target = Join-Path $Project "Mods\$plugin"
robocopy $source $target /MIR /NFL /NDL /NJH /NJS /NP | Out-Null
if ($LASTEXITCODE -ge 8) { throw "robocopy failed ($LASTEXITCODE)" }

$archive = Join-Path $Project "Saved\ArchivedPlugins\$plugin"
if (Test-Path $archive) { Remove-Item -Recurse -Force $archive }

& (Join-Path $Engine 'Engine\Build\BatchFiles\RunUAT.bat') "-ScriptsForProject=$uproject" PackagePlugin "-project=$uproject" `
	-clientconfig=Shipping -serverconfig=Shipping -utf8output "-DLCName=$plugin" -build -server -serverplatform=Win64 `
	-noclient -nocompileeditor -installed
if ($LASTEXITCODE -ne 0) { throw "PackagePlugin failed ($LASTEXITCODE)" }

$zips = @(Get-ChildItem $archive -Filter *.zip)
if ($zips.Count -ne 1) { throw "expected one archived zip in $archive, found $($zips.Count)" }
if (Test-Path $Out) { Remove-Item -Recurse -Force $Out }
Expand-Archive -Path $zips[0].FullName -DestinationPath $Out
if (-not (Test-Path (Join-Path $Out "$plugin.uplugin"))) { throw "the archive has no $plugin.uplugin at its root" }
Write-Output "built $plugin -> $Out ($($zips[0].Name))"
```

#include "SatisModS1b.h"
#include "HttpModule.h"
#include "Interfaces/IHttpRequest.h"
#include "Interfaces/IHttpResponse.h"

// check-api reads "Name(" as a call, so: an alias keeps parentheses out of Probe's parameter list (so it is seen as the
// spike's own function), the label is assigned rather than constructed, and the continuation has a lowercase name.
using ThenFn = TFunction<void()>;

// The bad-host probe starts only after the good one completes, so "s1b bad" is always the last line the harness waits for.
static void Probe(const TCHAR* Label, const TCHAR* Url, ThenFn next)
{
	auto Request = FHttpModule::Get().CreateRequest();
	Request->SetURL(Url);
	Request->SetVerb(TEXT("GET"));
	const FString Name = Label;
	Request->OnProcessRequestComplete().BindLambda([Name, next](FHttpRequestPtr Req, FHttpResponsePtr Response, bool bSucceeded)
	{
		if (bSucceeded && Response.IsValid())
		{
			UE_LOG(LogTemp, Display, TEXT("satis-mod s1b %s status=%d"), *Name, Response->GetResponseCode());
		}
		else
		{
			const TCHAR* Reason = Req.IsValid() ? LexToString(Req->GetFailureReason()) : TEXT("unknown");
			UE_LOG(LogTemp, Display, TEXT("satis-mod s1b %s error=%s"), *Name, Reason);
		}
		if (next) { next(); }
	});
	Request->ProcessRequest();
}

void FSatisModS1bModule::StartupModule()
{
	UE_LOG(LogTemp, Display, TEXT("satis-mod loaded"));
	Probe(TEXT("good"), TEXT("https://api.satis-manager.com/api/health"), []()
	{
		Probe(TEXT("bad"), TEXT("https://wrong.host.badssl.com/"), nullptr);
	});
}

IMPLEMENT_MODULE(FSatisModS1bModule, SatisModS1b)

#include "SatisModS2.h"
#include "HttpModule.h"
#include "Interfaces/IHttpRequest.h"
#include "Interfaces/IHttpResponse.h"

void FSatisModS2Module::StartupModule()
{
	UE_LOG(LogTemp, Display, TEXT("satis-mod loaded"));
	// First fire after 30 s, then every 30 s while PostNext returns true (Ticker.h:56).
	TickerHandle = FTSTicker::GetCoreTicker().AddTicker(TEXT("SatisModS2"), 30.0f, [this](float) { return PostNext(); });
}

void FSatisModS2Module::ShutdownModule()
{
	FTSTicker::RemoveTicker(TickerHandle);
}

bool FSatisModS2Module::PostNext()
{
	const int32 N = ++Sent;
	auto Request = FHttpModule::Get().CreateRequest();
	Request->SetURL(TEXT("http://127.0.0.1:18080/s2"));
	Request->SetVerb(TEXT("POST"));
	Request->SetHeader(TEXT("Content-Type"), TEXT("application/json"));
	Request->SetContentAsString(FString::Printf(TEXT("{\"spike\":\"S2\",\"n\":%d}"), N));
	Request->OnProcessRequestComplete().BindLambda([N](FHttpRequestPtr, FHttpResponsePtr, bool)
	{
		if (N == FSatisModS2Module::Total)
		{
			UE_LOG(LogTemp, Display, TEXT("satis-mod s2 done"));
		}
	});
	Request->ProcessRequest();
	return Sent < Total; // false after the 40th post removes the ticker
}

IMPLEMENT_MODULE(FSatisModS2Module, SatisModS2)
