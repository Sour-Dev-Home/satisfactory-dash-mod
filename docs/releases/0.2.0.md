# satis-dash agent 0.2.0

The first release of the satis-dash agent mod. **The mod no longer needs FicsitRemoteMonitoring (FRM).** It reads everything the dashboard shows from the game itself, and SML is its only dependency.

## If you are upgrading from 0.1.0

- **You can remove FRM from your server.** The mod never contacts it, and you no longer need to enable FRM's web server (`uWS.Autostart`).
- **Your existing config keeps working.** If it still has `frmPort`, `frmToken` or any of the old `*Source` keys, the mod loads normally and logs one line naming the keys it ignores. It never logs their values. The keys are dropped the next time the mod writes its config.
- **No re-enrolment is needed.** The mod talks to the backend through the same `/agent/v1` API.

## What the mod reads natively

- **Power:** circuits, generators with their fuel, and power lines.
- **Players** and **resource nodes.**
- **Factory:** machines, production rates, extractors and storage contents.
- **Trains and stations:** positions, timetable stops, cargo, and station transfer rates.
- **Map layers:** rails, conveyors (belts, lifts and pipes), map markers and drone routes.

Every reader matched FRM's own output before FRM was removed (ADR-0058 native-parity runs). The final all-reader parity run is 41340686528. The evidence is kept in the satis-dash repository under `docs-vault/raw-sources/mod-native-readers/`.

## Server cost

- Every game-thread read is sliced into steps of about 1 ms. The judged ceiling is 2 ms per step.
- A step the OS paused (the thread waiting rather than working) is reported, not counted as mod work.
- Validated by `tick-cost-native` and a 16-hour all-readers soak (run 41878531754, accepted by owner ruling).
- Generators are sent once per read rather than on every power update.

## Platforms

- **Windows dedicated server.** This build is built and tested on Windows only.
- **Linux servers aren't supported in this release.**

## Changes since 0.1.0

- Native readers for every layer. FRM, the FRM bridge and the `frmPort`, `frmToken` and `*Source` settings are removed (R7).
- `stepDiagnostics`: an optional config key, off by default. Test runs use it to add CPU-cycle and per-call timing to the over-ceiling log line.
